**Programs:** HackerOne · Bugcrowd · YesWeHack  
**Toolkit:** Linux · Bash · Python · Burp Suite · HTTP · REST APIs

**Rules I work by**
1. Authorized programs and in-scope assets only.
2. Minimal proof of concept, no access to data beyond what proves the issue.
3. Clear reports: impact, reproduction steps, remediation.
4. Nothing is published until the program has fixed it and allows disclosure.
